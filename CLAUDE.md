# CLAUDE.md — Developer Guide

This repo builds ML pipelines to predict Intracranial Pressure (ICP) in ICU patients. Two tasks are supported: **regression** (predict continuous ICP value) and **classification** (predict whether ICP ≥ 22 mmHg). Raw per-variable `.txt` files are parsed, cleaned, imputed, and enriched with lagged time-series features before being fed to scikit-learn / XGBoost models.

For a full technical reference, see `summary.md`.

---

## How to Run

```shell
# Classification pipeline
python src/main.py --mode classification --hours 5

# Regression pipeline
python src/main.py --mode regression --hours 5

# Descriptive statistics (standalone, no model training)
python src/generate_descriptive_stats.py
```

`--hours` controls the lagged feature lookback window (default: 5).

## Architecture

```
src/main.py                     ← entry point, orchestrates everything
src/data_parser/
  data_parser.py                ← parses raw .txt files → final_data.csv
  data_pre_processor.py         ← 10-step cleaning + lagged features
  binary_data_processor.py      ← ICP → binary label (threshold: 22 mmHg)
  time_series_processor.py      ← creates icp_lag_1 … icp_lag_N per variable
src/classification/
  classification_pipeline.py    ← runs 6 classifier variants + McNemar tests
  xgboost_classification_predictor.py
  lagged_icp_baseline_predictor.py
  latest_icp_baseline_predictor.py
src/regression/
  regression_pipeline.py        ← runs 4 models × 4 feature configs + CV
  baseline_*.py                 ← non-ML baselines (history, mean, windowed)
src/helper/
  data_frame_printer.py         ← DataFramePrinter.print_dataframe_tabulated()
src/generate_descriptive_stats.py  ← standalone cohort + clinical stats script
```

## Data Files

```text
data/
  *.txt                              — source: raw ICU measurements (never modify)
  pathologies_filtered.csv           — source: patient ID → pathology mapping
  final_data.csv                     — generated by DataParser
  cleaned_df_lagged_{mode}.csv       — generated by DataPreProcessor
  train_data_{mode}.csv              — generated by main.py
```

**All generated CSVs are cached.** Delete a file to force its step to re-run.
`clean_generated_files.sh` at the project root removes all generated files.

## Key Design Decisions — Do Not Change Without Care

| Decision | Value | Why |
|----------|-------|-----|
| Binary ICP threshold | **22 mmHg** | Clinical standard for elevated ICP intervention |
| ICP outlier Z-score cutoff | **7** | Intentionally permissive — domain-appropriate for medical extremes |
| Train/test split | **80/20, patient-level** | Prevents data leakage across patients |
| Cross-validation grouping | **StratifiedGroupKFold by patient_id** | Same reason |
| KNN imputation neighbours | **1** | Only rows with exactly 1 null are imputed; nearest-neighbour is sufficient |
| Classification class weight | **scale_pos_weight = 6** | Reflects ~6:1 negative:positive class ratio in the dataset |
| Baseline decision threshold | **15 mmHg** | Conservative detection threshold for rule-based baselines |
| Lag default | **5 hours** | Configurable via `--hours`; drives `icp_lag_1` … `icp_lag_5` etc. |

## Patterns & Conventions

**Printing tables** — use `DataFramePrinter` (or `tabulate` directly with `tablefmt="fancy_grid"`):
```python
from helper.data_frame_printer import DataFramePrinter
DataFramePrinter.print_dataframe_tabulated(df, title="My Title")
```

**Caching pattern** — check for file existence before generating:

```python
if os.path.exists(output_path):
    return pd.read_csv(output_path)
# ... generate ...
df.to_csv(output_path, index=False)
```

**Feature selection in pipelines** — lag features are identified by the string `'_lag_'` in the column name. Non-feature columns (`patient_id`, `date_of_birth`, `timestamp`) are excluded before fitting scalers or models.

**Regression mode auto-answers prompts** — in `pre_process_dataset`, interactive `input()` calls are bypassed when `mode == "regression"`. Classification mode asks the user.

## Gotchas

- **Interactive prompts block automation.** Several `input()` calls exist in `DataParser` and `DataPreProcessor` (see `summary.md` for the full list). Regression mode bypasses most of them; classification mode does not.
- **`icu_data_parser/` and `icu_data_regression_classes/` are dead code.** These directories are empty and are legacy remnants of an earlier refactor. Do not add code there.
- **`respiration_rate` is always dropped** in `drop_columns_with_high_missing_values()` due to high sparsity. It remains in `CLINICAL_COLUMNS` in `generate_descriptive_stats.py` for reporting purposes only (labelled "dropped").
- **`peep` uses 0 as its missing-value sentinel** (not -1 like other variables). This is intentional — a PEEP of 0 is a valid clinical value for some patients.
- **Age computation** in `generate_descriptive_stats.py` uses each patient's first measurement timestamp as a proxy for ICU admission date.
